#### C++
---
source code -> (1) compile -->  file.o (mac / windows / linux) --> file.exe --> (2) run
file.o is machine code and can't run
file.exe is also machine code and can run but can't run across OS
#### JAVA
---
file.java         -> (1) javac     --> file.class                                   --> (2) java -> run
                        (bytecode;java)
***Write once run anywhere***
because you can use JRE to run file.class anywhere

#### JDK vs JRE
---
JDK can compile (javac & java)
JRE can only run (java)
